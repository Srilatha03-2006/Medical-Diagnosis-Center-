Medical Diagnosis Center by ServiceNow Service Portal

Project Overview

The Medical Diagnosis Center by ServiceNow Service Portal is a web-based application designed to simplify diagnostic center operations. It provides a centralized platform for managing patient information, diagnostic tests, appointments, and laboratory reports.

The application is developed using the ServiceNow platform and Service Portal, with widgets, application tables, and server-side logic to support its functionality.

Objectives

- Simplify diagnostic test management.
- Organize patient and appointment information.
- Provide an interface to view and manage appointments.
- Support access to laboratory report information.
- Improve the efficiency of diagnostic center operations.

Key Features

- Test Catalog: View available diagnostic tests.
- Patient Management: Manage patient information.
- Appointment Booking: Submit diagnostic test appointment requests.
- My Appointments: View appointment records and statuses.
- Lab Reports: Access available laboratory report information.
- Service Portal: Access application features through a centralized interface.
- Workflow Automation: Support selected automated processes using configured ServiceNow flows.

Technology Stack

- Platform: ServiceNow
- User Interface: ServiceNow Service Portal
- Frontend Components: Service Portal Pages and Widgets
- Backend Logic: ServiceNow Server-Side Scripting
- Data Storage: ServiceNow Application Tables
- Automation: ServiceNow Flows, where configured

Application Components

The application uses the following tables:

- Patient Table
- Appointment Table
- Diagnostic Test Table
- Report Table

The main portal interfaces include Test Catalog, My Appointments, and Lab Reports.
